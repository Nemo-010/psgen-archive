## Partially addressed, on purpose

- **#4** -- the subtree count is fixed (40-row stop: `33/35/34` before, `40/40/40`
  after, three runs each) and an unreadable live PID now counts as failed instead
  of skipped. The *zombie* half is not fixed: a `Z` still accepts a signal, and
  whether `stopped` should exclude it changes what the count means.
- **#17** -- `--local` now overrides `--utc-offset` (`TZ=Asia/Kolkata`: local+120
  gave 09:50 before, 07:50 after). The unbounded `--utc-offset` is not fixed.
- **#16** -- the shortfall is now warned about instead of silent; the padding and
  the count semantics are untouched.
- **#22** -- the help now says a one-field line is proc-self only; the form itself
  is unchanged.
- **#27** -- `After=sysinit.target` instead of a target that does not exist. The
  restart itself still depends on #1 (which this closes) and on `ExecStop=-`.

## Not touched, because the fix is a design decision

#20 (proposed patch, **not run as root here** -- treat as a proposal), #23
`load --mem-util`, #24 `log --lines`, #25 fd 3 config trust, #28 impossible values.
Each has the trade-offs written down in its issue.

## Notes for review

- This is the QA bundle's combined patch, unmodified in substance, split into
  commits by area. `git diff main..HEAD` differs from that patch only by the three
  `tests/invariants.py` hunks for #6 -- added because the bundle's patch alone still
  aborts the suite on a host with a finite hard `RLIMIT_FSIZE` or no `/dev/ptmx`.
  That is worth knowing if you were planning to apply the patch as-is.
- Each commit builds on its own (`cargo build --release` at every step), so it
  bisects.
- `cargo clippy --release` reports the same 23 warnings as `bf80156`; this adds
  none. `cargo fmt --check` still fails, identically before and after -- the hits
  are pre-existing and in files this does not touch.
- Two commits change generated output on purpose: `%MEM` now rounds like procps,
  and postgres rows become children of the postmaster. Both move golden output and
  both are argued in their issues.
